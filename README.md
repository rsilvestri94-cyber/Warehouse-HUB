# Progetto Warehouse Vestas

Warehouse HUB Organizer — app React + TypeScript + Tailwind CSS v4 (Vite), con autenticazione Google e sincronizzazione dati su Firebase (progetto `vestas-warehouse-hub`).

Il file statico originale (vanilla JS/HTML/CSS) è conservato in [`legacy/index.html`](legacy/index.html) come riferimento.

## Sviluppo

```bash
pnpm install
pnpm dev
```

## Build di produzione

```bash
pnpm build
pnpm preview
```

L'output va nella cartella `dist/`, pronta per essere pubblicata su qualsiasi hosting statico (es. Firebase Hosting, GitHub Pages, Netlify).
